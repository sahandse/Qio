# کیو — راه‌اندازی نسخه دسکتاپ (Windows / macOS)

## ۱. اجرا و نصب
این پروژه با Tauri 2، Rust، TypeScript و Node.js 22 توسعه یافته است.

```bash
npm install
npm test
npm run tauri dev
```

برای خروجی نصب: `npm run tauri build`. در GitHub از قسمت Actions → **Qio desktop build** خروجی‌های Windows و macOS قرار می‌گیرند، البته فقط اگر Build همان سیستم‌عامل با موفقیت انجام شده باشد. امضای دیجیتال و notarization برای انتشار عمومی macOS نیازمند حساب و گواهی معتبر است.

## ۲. رابط اصلی
پنجره بدون قاب، Always on Top، حالت کوچک/بزرگ، System Tray (نمایش، پنهان‌کردن، خروج)، هفت حالت کاراکتر و اعلان‌های اختیاری با اجازه کاربر پیاده‌سازی شده‌اند.

### زبان فارسی
همهٔ متن‌های رابط — جزیره، ابزارها، تنظیمات، صفحهٔ Flow، منوی Tray و اعلان‌ها — به فارسی ترجمه شده‌اند.

- انتخاب: تنظیمات ← عمومی ← زبان ← **فارسی**. با «System»، کیو زبان ویندوز یا لینوکس شما را می‌خواند و روی سیستم‌های فارسی‌زبان خودش فارسی را برمی‌گزیند.
- تغییر زبان نیازی به اجرای دوبارهٔ برنامه ندارد؛ همهٔ پنجره‌ها جا‌به‌جای خود ترجمه می‌شوند.
- راست‌به‌چپ: کارت‌ها، متن چت و تنظیمات راست‌به‌چپ می‌شوند؛ کد، فرمان‌ها، مسیر فایل‌ها، کلیدهای API و شبکهٔ فعالیت عمداً چپ‌به‌راست می‌مانند.
- اعداد آمار را همان زبان می‌نویسد (۱٬۲۳۴).
- قلم: در حالت فارسی، کیو اول Vazirmatn را امتحان می‌کند و اگر نصب نباشد Tahoma ویندوز را می‌گیرد. برای نمایش زیباتر، Vazirmatn را از <https://github.com/rastikerdar/vazirmatn> نصب کنید.

## ۳. وصل‌کردن مستقیم Claude Code
در پوشه پروژه، به‌صورت **دستی** دستور زیر را اجرا کنید:

```bash
npm run setup:claude
```

این دستور قبل از تغییر تنظیمات Claude Code، نسخه پشتیبان می‌سازد و Hookهای کیو را به تنظیمات موجود اضافه می‌کند. Claude Code را بعد از تنظیمات یک‌بار راه‌اندازی مجدد کنید.

- Hookهای معمولی فقط **نام ابزار و نوع رویداد** را ثبت می‌کنند؛ متن مکالمه و کد منتقل نمی‌شود.
- Hook `PermissionRequest` فقط **با تأیید صریح کاربر** از داخل کیو پاسخ می‌دهد.
- اگر برنامه کیو فعال نباشد یا مهلت درخواست سپری شود، Hook بدون تصمیم خارج می‌شود تا خود Claude Code پنجره مجوز را نشان دهد.
- **هرگز تأیید خودکار وجود ندارد.** قبل از اجازه‌دادن به ابزار، جزئیات نمایش‌داده‌شده را بررسی کنید.

## ۴. اتصال رویدادهای Cursor

برای اتصال اختیاری Cursor، از پوشهٔ پروژه Qio اجرا کنید:

```bash
npm run setup:cursor
```

این دستور `~/.cursor/hooks.json` را با حفظ تنظیمات موجود به‌روزرسانی و قبل از تغییر نسخهٔ پشتیبان ایجاد می‌کند. Hookهای Cursor به‌صورت خودکار دوباره بارگذاری می‌شوند؛ اگر رویدادی دیده نشد، بخش Settings → Hooks را بررسی کنید. Qio فقط نام Agent، نوع رویداد و نام ابزار را در `~/.qio/events.jsonl` ثبت می‌کند و متن prompt، فرمان کامل، مسیر فایل و محتوای فایل را ذخیره نمی‌کند. این اتصال فقط فرادادهٔ فعالیت است، نه دسترسی کامل به Cursor یا مدل‌های داخلی آن.

## ۵. سایر Agentها
اسکریپت `scripts/qio-hook.mjs` از رویدادهای رایج و نام‌های سازگار با Claude، Gemini CLI، Cursor و OpenCode پشتیبانی می‌کند؛ اما باید Hook متناظر با نسخه ابزار را دستی در تنظیمات همان ابزار پیکربندی کنید. این بخش هنوز راه‌انداز اختصاصی و تأییدشده برای تک‌تک ابزارها ندارد.

Codex و Claude Code بدون Hook هم امکان شناسایی **تاریخچه نشست محلی** دارند، که با کنترل زنده تفاوت دارد.

## ۶. اتصال Qoder IDE و ثبت رویدادها

Qio از Hookهای رسمی Qoder پشتیبانی می‌کند. برای نصب اتصال، در پوشه پروژه اجرا کنید:

```bash
npm run setup:qoder
```

این اسکریپت `~/.qoder/settings.json` را با حفظ تنظیمات قبلی به‌روزرسانی و پیش از تغییر از آن نسخه پشتیبان می‌سازد. سپس Qoder را کامل ببندید و دوباره باز کنید. Hookها فقط نام عامل، نوع رویداد و نام ابزار را در `~/.qio/events.jsonl` ثبت می‌کنند؛ متن گفتگو، prompt، فرمان کامل و محتوای فایل‌ها ثبت نمی‌شود. این اتصال رویدادهای Agent را به Qio می‌رساند و به معنی استفاده از مدل Qoder در چت مستقل Qio نیست.

## ۷. شاهد واقعی نتیجه تست
برای ثبت کد خروج واقعی یک دستور تست:

```bash
npm run test:code
```

این دستور صرفاً تست‌های خود پروژه Qio را اجرا می‌کند و نتیجه را در `~/.qio/test-results.jsonl` ثبت می‌کند. برای تست یک پروژه دیگر، از:
```bash
node scripts/qio-test.mjs -- npm test
```
در پوشه همان پروژه و با مسیر صحیح اسکریپت استفاده کنید. کد خروج صفر به معنی موفقیت اجرای **همان دستور** است؛ به معنی بررسی کیفیت تمامی تغییرات، تمام تست‌ها یا تازه‌بودن نتیجه نسبت به جدیدترین کد نیست.

## ۸. هوش مصنوعی مستقل
گفت‌وگوی مستقیم با Claude از API رسمی Anthropic (متغیر `ANTHROPIC_API_KEY`)، AvalAI و Hooshgar (ایرانی)، OpenAI، OpenRouter، DeepSeek، Groq، Together، Ollama و LM Studio. اشتراک Claude یا ChatGPT به‌خودی‌خود اعتبار API ایجاد نمی‌کند.

در تنظیمات کیو می‌توانید ثبت فرادادهٔ جدید Hookها را خاموش کنید؛ تاریخچهٔ قبلی فقط با پاک‌کردن دستی حذف می‌شود. کلیدهای API را فقط با متغیرهای محیطی تنظیم کنید؛ داخل گیت‌هاب ننویسید. برای Ollama و LM Studio باید سرور محلی و مدل از قبل راه‌اندازی شده باشند.

## ۹. حریم خصوصی
همه رویدادها و تصمیم‌های مجوز در پوشه محلی `~/.qio` نگهداری می‌شوند. پیش‌نمایش محدود درخواست مجوز می‌تواند شامل بخشی از دستور ابزار باشد؛ این اطلاعات فقط برای نمایش درخواست به صورت موقت در کامپیوتر ذخیره می‌شود و بعد از پاسخ یا پایان Hook حذف خواهد شد. کیو به‌صورت مستقل کد یا فرمانی اجرا نمی‌کند، مگر اینکه کاربر خودش دستور تست را اجرا کند.

## ۱۰. وضعیت و محدودیت‌ها
با اینکه کدها ثبت شده‌اند، نتیجهٔ موفقیت کامل Build و کارکرد نصب‌کننده هنوز از راه دور تأیید نشده است. پشتیبانی از تأیید مجوز در Codex و سایر Agentها، تحلیل کامل Diff، اثبات تازه‌بودن تست‌ها و سیستم به‌روزرسانی خودکار هنوز در حد قابلیت نهایی قابل‌اعتماد تکمیل نشده‌اند.

مرجع تجربه کاربری: Coucou و DotPals. برند و کاراکتر کیو مستقل است.
