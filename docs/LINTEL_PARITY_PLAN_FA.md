# نقشه اجرای قابلیت‌های پیشرفته Qio

این سند برنامه اجرایی پروژه است؛ مواردی که هنوز در سورس پیاده‌سازی و با خروجی واقعی آزمایش نشده‌اند «در انتظار» محسوب می‌شوند، نه تکمیل‌شده.

## اصول ثابت
- هسته چت و ارائه‌دهندگان فعلی Qio حفظ می‌شود.
- وضعیت Agent فقط از رویداد یا فایل واقعی گزارش می‌شود؛ وجود پوشه به معنی نشست فعال نیست.
- هیچ درخواست مجوزی خودکار تأیید نمی‌شود.
- کلید API و متن خصوصی جلسه‌ها در لاگ یا UI تشخیصی نمایش داده نمی‌شود.
- هر قابلیت باید روی پلتفرم هدف قابل‌ساخت باشد و تست مستقل داشته باشد.
- UI فارسی/انگلیسی، RTL/LTR، کاهش حرکت و پنجره شفاف باید حفظ شوند.

## ترتیب اجرا

### 1. پایه و کیفیت انتشار
- [x] CI ویندوز و تست رابط موجود
- [x] ثبت وضعیت ساخت از GitHub Actions
- [ ] اجرای تست‌ها روی همان SHA که قرار است منتشر شود
- [ ] بررسی نسخه و نام فایل‌های واقعی Release
- [ ] تست نصب/حذف و حفظ تنظیمات

### 2. Agentها و وضعیت واقعی
- [ ] آداپتورهای جداگانه و نسخه‌پذیر برای Claude Code، Cursor، Qoder و Codex
- [ ] تشخیص وضعیت‌های configured / detected / active / waiting / completed با شواهد واقعی
- [ ] داشبورد زنده با زمان آخرین رویداد و بازکردن مسیر نشست
- [ ] کنترل تکرار، چرخش لاگ و پاک‌سازی امن داده‌های محلی
- [ ] تست با نمونه رویدادهای مصنوعی و تست دستی روی ابزار نصب‌شده

### 3. مرکز تأیید و تغییرات کد
- [ ] کارت درخواست تأیید فقط بر پایه رویداد واقعی Agent
- [ ] نمایش جزئیات امن و diff قبل/بعد
- [ ] تأیید/رد دستی؛ هرگز auto-approve
- [ ] ثبت نتیجه تصمیم و تست مسیرهای رد، لغو و خطا

### 4. چت و مدل‌ها
- [x] اتصال فعلی به ارائه‌دهندگان تعریف‌شده در Rust
- [ ] انتخاب مدل از فهرست واقعی endpoint یا مدل‌های محلی، نه فهرست ساختگی
- [ ] ذخیره امن کلیدها در credential store سیستم‌عامل
- [ ] تاریخچه قابل‌حذف، خطاهای قابل‌فهم، محدودیت درخواست و وضعیت اتصال
- [ ] تست آنلاین با کلید کاربر و تست محلی با Ollama/LM Studio

### 5. اعلان‌ها و جمع‌بندی
- [x] اعلان رخدادهای واقعی فقط با فعال‌بودن اعلان‌ها و اجازهٔ سیستم
- [ ] جمع‌بندی دوره‌ای از فراداده/خروجی مجاز؛ نمایش شفاف محدودیت داده
- [x] کنترل opt-in جداگانه برای رویداد Agent و درخواست تأیید، سکوت ۳۰ دقیقه‌ای و حذف تکرار یک پیام تا ۶۰ ثانیه

### 6. پوسته شناور و تجربه دسکتاپ
- [ ] باز/بسته‌شدن هوشمند و رفتار درست هنگام fullscreen
- [ ] جابه‌جایی آزاد، انتخاب نمایشگر و سازگاری با DPI
- [x] میان‌برهای صفحه‌کلید برای تنظیمات، باز/بسته‌کردن و خروج از پنل
- [x] جست‌وجوی زنده گزینه‌های تنظیمات
- [ ] تنظیمات ماژولار، اسکرول و ترجمه کامل
- [ ] بررسی واقعی شفافیت پنجره در Windows و macOS

### 7. ابزارهای سیستم
- [x] API داخلی برای خواندن CPU، حافظه، فضای دیسک و شمارنده‌های تجمعی شبکه از داده‌های سیستم واقعی
- [x] داشبورد UI برای نمایش و بروزرسانی CPU، حافظه، دیسک و شمارنده‌های تجمعی شبکه
- [ ] باتری، صدا و روشنایی فقط در سیستم‌هایی که API پشتیبانی می‌کند
- [ ] تایمر، پومودورو، تقویم و یادآورها با ذخیره محلی
- [ ] کنترل‌های حساس با اجازه صریح و بازگردانی امن تنظیمات

### 8. رسانه و ابزار صفحه
- [ ] کنترل رسانه با API سیستم‌عامل و وضعیت واقعی پخش
- [ ] اسکرین‌شات، حاشیه‌نویسی و انتخاب رنگ
- [ ] ضبط صفحه با نشانگر واضح ضبط و توقف قابل‌دسترس
- [ ] تست مجوزها و توقف کامل ضبط/میکروفون/دوربین

### 9. دستیار صوتی
- [ ] گفتار به متن با شروع صریح کاربر
- [ ] پاسخ صوتی و فرمان‌های محدود و قابل‌تأیید
- [ ] بیدارباش صوتی خاموش به‌صورت پیش‌فرض
- [ ] نشانگر سخت‌افزار فعال، خاموش‌شدن سریع و تست حریم خصوصی

### 10. آماده‌سازی انتشار
- [ ] تست‌های واحد و رابط روی آخرین commit
- [ ] Build ویندوز و macOS در workflowهای مستقل
- [ ] نصب تمیز، ارتقا از نسخه قبلی، حذف و بازگشت تنظیمات
- [ ] تأیید دستی همه قابلیت‌هایی که به سخت‌افزار/API واقعی وابسته‌اند
- [ ] انتشار فقط وقتی که assetها و نسخه واقعی با tag هم‌خوان باشند

## وضعیت
این سند نقشه راه است و به‌تنهایی به معنی تکمیل قابلیت‌ها نیست. هر خانه فقط پس از تغییر کد و تأیید تست مربوط علامت زده می‌شود.
