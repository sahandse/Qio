# اتصال مستقل هوش مصنوعی در کیو

کیو برای **گفت‌وگو** مستقیماً از هسته Rust به API سرویس انتخابی درخواست می‌فرستد؛ به DotPals، Coucou یا سرویس واسط اختصاصی نیاز ندارد. برای پاسخ کاملاً آفلاین، باید Ollama یا LM Studio و یک مدل دانلودشده از قبل روی کامپیوتر نصب و اجرا شده باشد. خود کیو هنوز موتور اجرای مدل زبانی داخلی ندارد.

## ارائه‌دهندگان
| ارائه‌دهنده | شناسه | متغیر محیطی API |
|---|---|---|
| اول‌ای‌آی، ایرانی | avalai | AVALAI_API_KEY |
| هوشگر، ایرانی | hooshgar | HOOSHGAR_API_KEY |
| OpenAI | openai | OPENAI_API_KEY |
| OpenRouter | openrouter | OPENROUTER_API_KEY |
| DeepSeek | deepseek | DEEPSEEK_API_KEY |
| Groq | groq | GROQ_API_KEY |
| Together AI | together | TOGETHER_API_KEY |
| Ollama محلی | ollama | بدون کلید |
| LM Studio محلی | lmstudio | بدون کلید |

این‌ها اتصال‌های OpenAI-compatible با مسیرهای ثابت هستند؛ **مدل‌های در دسترس، تعرفه و سازگاری هر مدل به حساب و ارائه‌دهنده بستگی دارند.** کیو شناسه مدل را از کاربر می‌گیرد تا نام مدل اشتباه یا ساختگی نمایش ندهد.

آدرس‌های API در سورس Rust ثابت‌اند. کلیدها داخل GitHub، localStorage یا تنظیمات متنی کیو ذخیره نمی‌شوند؛ پیش از اجرای برنامه باید متغیر محیطی موردنیاز روی سیستم تنظیم شده باشد و برنامه مجدد اجرا شود. هیچ کلیدی نباید در Issues یا Screenshots منتشر شود.

## آنچه هنوز مستقل نشده
نظارت زنده کامل بر ابزارهای CLI، تأیید/رد مجوزها و شناسایی اثبات‌پذیر نتایج تست‌ها نیازمند ساخت آداپتور اختصاصی برای هر Agent است. نمایش تاریخچه Codex و Claude فقط شناسایی نشست است. هیچ پیوند DotPals برای گفت‌وگوی هوش مصنوعی لازم نیست.

## امنیت
تنها ارائه‌دهنده‌های ثابت و شناخته‌شده یا آدرس لوپ‌بک محلی پذیرفته می‌شوند؛ URL دلخواه اجرا نمی‌شود و redirect غیرفعال است. درخواست‌ها محدودیت حجم متن و زمان پاسخ دارند. متن پیام با انتخاب کاربر فقط به ارائه‌دهنده همان انتخاب ارسال می‌شود.
