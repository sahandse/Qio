# 🪟 بیا کیو رو روی ویندوز نصب کنیم!

> کیو هنوز داره کامل‌تر می‌شه 💙 لینک پایین رو باز کن، ولی حواست باشه **ممکنه هنوز فایل نصب آماده‌ای اونجا نباشه**.

[مشاهده Buildهای ویندوز در GitHub Actions](https://github.com/sahandse/Qio/actions/workflows/ui-check.yml)

## روش اول: فایل آماده رو بگیر (اگه ساخته شده باشه)
1. اول لینک بالا رو باز کن.
2. از بین اجراهای شاخه `main`، یکی رو انتخاب کن که علامتش **سبز و موفق** باشه.
3. پایین صفحه دنبال **Artifacts** بگرد؛ اگه `Qio-windows-latest` واقعاً بود، دانلودش کن.
4. فایل ZIP رو از حالت فشرده خارج کن.
5. داخل بسته، فایل نصب `.exe` (NSIS) یا `.msi` را اجرا کنید؛ نوع فایل ممکن است بر اساس خروجی Build متفاوت باشد.
6. مراحل نصب رو ادامه بده و بعد از منوی Start، **Qio** رو باز کن. 🎉
7. اگر Windows SmartScreen به‌دلیل امضای ناشناخته هشدار داد، تنها پس از بررسی منشأ فایل و اطمینان از GitHub رسمی پروژه ادامه دهید؛ فایل امضانشده برای انتشار عمومی هنوز نیاز به امضای معتبر دارد.

## روش دوم: دوست داری خودت کیو رو بسازی؟
1. **Node.js 22**، **Rust** و **Microsoft C++ Build Tools** را از منابع رسمی نصب کنید.
2. از نصب‌بودن **Microsoft Edge WebView2 Runtime** مطمئن شوید.
3. مخزن را با Git Clone کنید:
   ```powershell
   git clone https://github.com/sahandse/Qio.git
   cd Qio
   ```
4. وابستگی‌ها، تست‌ها و محیط توسعه را اجرا کنید:
   ```powershell
   npm install
   npm test
   npm run tauri dev
   ```
5. پس از بررسی برنامه، نسخه قابل نصب بسازید:
   ```powershell
   npm run tauri build
   ```
6. پوشه `src-tauri/target/release/bundle/nsis` یا `msi` را بررسی کنید. اگر Build ناموفق بود، فایل نصب معتبری ساخته نشده است.

## وصل‌کردن Claude Code (اختیاری)
1. ابتدا Claude Code را جداگانه نصب کنید و از کارکرد آن مطمئن شوید.
2. در ریشه پروژه Qio، `npm run setup:claude` را اجرا کنید.
3. Claude Code را مجدد باز کنید.
4. برای درخواست‌های مجوز، در پنل فعالیت‌ها تصمیم را با دقت بررسی کنید؛ **اجازه خودکار وجود ندارد**.

## اگه یه‌جا گیر کردی...
- پنجره خالی: WebView2، گزارش کنسول و اجرای `npm run build` را بررسی کنید.
- مدل هوش مصنوعی کار نمی‌کند: کلید API، شناسه مدل و اتصال اینترنت یا سرویس محلی را بررسی کنید.
- نسخه قبلی در ویندوز اجرا نمی‌شود: ابتدا خروجی Build جدید را آزمایش کنید؛ پاک‌کردن داده‌های شخصی بدون پشتیبان توصیه نمی‌شود.
