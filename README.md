# کیو — Qio

کیو یک همراه مینیمال فارسی برای نظارت بر فعالیت دستیارهای کدنویسی است؛ با جزیره شناور، شخصیت زنده و پنل وضعیت.

## وضعیت

این مخزن در مرحلهٔ پیاده‌سازی اولیه است. نمایش نمونهٔ رابط به معنی اتصال واقعی به ابزارهای AI نیست.

## معماری

- Desktop: Tauri 2 + TypeScript / CSS — هدف: Windows و macOS
- Android: برنامهٔ همراه در مرحلهٔ بعد؛ اتصال از طریق ارتباط امن با دسکتاپ
- فارسی و راست‌به‌چپ، حالت تاریک، دسترس‌پذیری و انیمیشن سبک

## اجرا (پس از نصب Node.js و Rust)

```sh
npm install
npm run tauri dev
```

## الهام و حقوق

Qio از ایدهٔ Coucou الهام می‌گیرد. نام، شخصیت Mochi، نمادها و صداهای Coucou در این پروژه استفاده نمی‌شوند. استفادهٔ احتمالی از کد منبع Coucou فقط با حفظ اعلان مجوز MIT و حق نشر امکان‌پذیر است.
