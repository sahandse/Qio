# کیو — Qio

همراه کوچک و فارسی برنامه‌نویسی برای **Windows** و **macOS**، با جزیره شناور و کاراکتر متحرک اختصاصی.

> نسخهٔ توسعه‌ای 0.1.0. سورس و امکانات ثبت شده‌اند؛ موفقیت نهایی Build و نسخهٔ قابل انتشار هنوز تأیید نشده است.

## قابلیت‌های پیاده‌سازی‌شده در کد
- رابط فارسی RTL، جزیره بدون قاب و همیشه‌روی‌صفحه، کنترل کشیدن و باز/بسته‌کردن
- هفت حالت انیمیشن کاراکتر، کاهش حرکت، System Tray با نمایش/پنهان‌کردن/خروج
- اعلان بومی با فعال‌سازی اختیاری و اجازهٔ کاربر
- شناسایی مستقیم فایل نشست‌های محلی Codex و Claude Code
- Hook مستقل کیو برای رویدادهای Claude و تعدادی قالب رویداد عمومی؛ بدون نیاز به Coucou/DotPals
- تأیید و رد **دستی** درخواست مجوز Claude Code از پنل کیو (Hook اختیاری و محدود به زمان)
- ثبت کد خروج واقعی دستورهای تست؛ بدون ادعای صحت تازه‌ترین نسخه کد
- گفت‌وگوی مستقیم با AvalAI، Hooshgar، OpenAI، OpenRouter، DeepSeek، Groq، Together AI، Mistral AI، xAI Grok، Fireworks AI، Cerebras، Ollama و LM Studio

- راهنمای تصویری درون برنامه برای هر یک از ۱۳ ارائه‌دهنده، با مراحل اختصاصی و لینک رسمی

## راه‌اندازی

```bash
npm install
npm test
npm run tauri dev
```

راه‌اندازی Hook اختیاری Claude Code پس از بررسی تنظیمات:

```bash
npm run setup:claude
```

ساخت نسخهٔ دسکتاپ:

```bash
npm run tauri build
```

## محدودیت‌ها
- اجرای Hookهای Gemini CLI، Cursor و OpenCode نیازمند پیکربندی متناسب با نسخهٔ هر ابزار است؛ اتصال سراسری و تأییدشده وجود ندارد.
- تحلیل کامل diff، اثبات اجرای جدیدترین تست‌ها، تأیید مستقل Codex و امکانات پیشرفته Coucou/DotPals هنوز تکمیل نشده‌اند.
- نصب‌کننده‌های unsigned ممکن است توسط سیستم‌عامل محدود شوند؛ برای macOS عمومی signing/notarization لازم است.
- هیچ فرمانی در کیو به‌صورت خودکار تأیید نمی‌شود.

## مالکیت و مجوز
کیو از ایده‌های UX پروژه‌های [Coucou](https://github.com/Louis-CFM/coucou) و [DotPals](https://github.com/Rikinshah787/dotpals) الهام گرفته، اما کاراکتر و برند مستقلی دارد. هنگام استفاده از کد منبع سایر پروژه‌ها، مجوز و اعلان‌های کپی‌رایت باید حفظ شوند.
