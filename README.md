# Qio

**یک نچ زنده بالای صفحه ویندوز.**

Qio لبهٔ بالایی صفحهٔ ویندوز را به یک نچ کوچک و زنده تبدیل می‌کند: آهنگ در حال پخش با متن هم‌زمان، تایمر پومودورو، یادآور آب و حرکت، قفسهٔ فایل، لیست کارها، بازی‌های تیم‌های مورد علاقه‌ات و یک جعبهٔ ابزار (قهوه، ماشین‌حساب، مونیتور سیستم، انتخاب رنگ از صفحه و اجرای سریع) — نچ همیشه بالاست، اما ساعتش هر ۱۰ دقیقه یک‌بار کوتاه سر می‌زند.

ویندوز ۱۰ (نسخه ۱۸۰۹ به بعد) و ویندوز ۱۱، ۶۴ بیت. ساخته‌شده با Electron + Vite + React + TypeScript، بدون ماژول نیتیو.

---

## قابلیت‌ها

- **پنجرهٔ نچ** — بدون قاب، شفاف، همیشه روی بقیه پنجره‌ها، در مرکز بالای صفحه و همیشه پیدا؛ فقط ساعتِ روی آن است که استراحت می‌کند. به‌صورت پیش‌فرض ساعت هر ۱۰ دقیقه یک‌بار حدود ۱۲ ثانیه سر می‌زند و بعد محو می‌شود؛ با بردن ماوس روی نچ یا باز کردن یک پنل همان‌جا می‌ماند. در تنظیمات → عمومی می‌توانید ساعت را همیشه پیدا کنید یا فاصله و مدت نمایشش را عوض کنید. در حالت جمع‌شده اگر بازی زنده‌ای در جریان باشد، دورهٔ تمرین بدود یا فنجان قهوه روشن باشد، جای ساعت یک نشان زنده می‌آید — نتیجه و دقیقهٔ بازی، شمارش معکوس تمرین، یا فنجان با زمان باقی‌مانده — و ساعت با اولین فرصت برمی‌گردد. حالت «نچ حداقلی» حالت جمع‌شده را به یک خط نازک تبدیل می‌کند (برای لپ‌تاپ‌هایی با حاشیهٔ بالای ضخیم).
- **ساعت و تقویم شمسی** — ساعت ۲۴ساعتهٔ فارسی در نچ و تقویم شمسی کامل در پنل؛ با شروع هفته از شنبه، شبکهٔ ماهانه، مناسبت‌های ملی، برجسته‌شدن امروز و جمعه‌ها، و شمارش معکوس نوروز.
- **آهنگ در حال پخش** — هر پخش‌کننده‌ای که در پنل رسانهٔ ویندوز دیده شود (Spotify، Apple Music، مرورگرها، Windows Media Player): تصویر آلبوم، عنوان/خواننده، پخش/توقف، بعدی/قبلی و جابه‌جایی موقعیت، همه از طریق SMTC.
- **متن هم‌زمان آهنگ** — دریافت متن از [LRCLIB](https://lrclib.net)؛ هر خط هنگام خوانده‌شدن روشن می‌شود و کلیک روی هر خط به همان نقطهٔ آهنگ می‌رود.
- **تایمر تمرین (پومودورو)** — دوره‌های کار/استراحت کوتاه/استراحت بلند با صدای زنگ نرم؛ شمارش معکوس در حالت جمع‌شدهٔ نچ هم دیده می‌شود.
- **یادآور آب** — اندازهٔ بطری، هدف روزانه و ساعات یادآوری، نمودار هفت روز اخیر و یک یادداشت کوتاه داخل نچ وقتی زمان نوشیدن رسید.
- **یادآور حرکت** — اگر طولانی پشت میز نشسته باشی نچ می‌گوید بلند شو و چند قدم بزن؛ بازه، ساعات فعال و اعلان ویندوزش در تنظیمات → آب و تمرکز است. پنج دقیقه بی‌حرکتی واقعاً استراحت حساب می‌شود، نه ادامهٔ نشستن، و دکمهٔ «بلند شدم» شمارش را از نو شروع می‌کند.
- **قفسهٔ فایل** — فایل‌ها را روی نچ بکشید تا نزدیکتان بماند، بعد بیرون بکشید داخل چت یا پوشهٔ دیگر. Qio فقط مسیر فایل را نگه می‌دارد، کپی نمی‌کند.
- **لیست کارها** — وظیفه با زمان دلخواه؛ وقتی موعد رسید نچ به شما یادآوری می‌کند.
- **بازی‌های فوتبال** — تا ده تیم را در تنظیمات → فوتبال انتخاب می‌کنی و فقط روزهایی که یکی از آن‌ها بازی دارد تب «بازی‌ها» در نچ ظاهر می‌شود: نتیجه و دقیقهٔ زنده، لوگوی دو تیم، و تایم‌لاین رویدادها (گل، پنالتی، کارت زرد و قرمز، تعویض، VAR) با دقیقه و نام بازیکن. همان صفحه یک تب «جدول» هم دارد: جدول کامل لیگِ تیم‌های انتخاب‌شده (رده، بازی، برد، مساوی، باخت، گل زده و خورده، تفاضل و امتیاز) با ردیفِ تیم‌های خودت، رنگ‌های صعود و سقوط، و برداشت تازه از ورزش۳ هر ده دقیقه. گل، سوت شروع، کارت قرمز و پایان بازی به‌صورت نوتیف در نچ می‌آید. داده‌ها بدون کلید از API عمومی ورزش۳ می‌آید و لوگوها در همان دستگاه به تصویر محلی تبدیل می‌شوند.
- **یادداشت‌ها** — یک فکر کوتاه را همان‌جا در نچ بنویس؛ با چهار رنگ، سنجاق به بالای فهرست و ویرایش با یک کلیک. همه‌چیز محلی ذخیره می‌شود.
- **اعلان‌ها** — هر نوتیفیکیشنی که Qio می‌فرستد در صفحهٔ «اعلان‌ها» می‌ماند و همان‌جا می‌شود جوابش را داد: «انجام شد» یا «۱۰ دقیقهٔ دیگر» برای کارها، «نوشیدم» برای آب، و میان‌برهایی مثل «باز کردن بازی‌ها» و «دیدن قفسه». یک نشانگر، تعداد خوانده‌نشده‌ها را روی تب نگه می‌دارد. اگر در تنظیمات → عمومی روشن باشد، اعلان‌های دیگر برنامه‌های ویندوز هم آینه می‌شوند؛ آن‌ها فقط خواندنی‌اند، چون ویندوز به برنامه‌های دیگر اجازهٔ پاسخ نمی‌دهد. فهرست فقط در حافظه است و با بستن Qio پاک می‌شود.
- **هوش مصنوعی داخل نچ** — نه لینک، بلکه یک گفت‌وگوی واقعی. در تنظیمات → هوش مصنوعی سرویس را انتخاب می‌کنید (Qoder، OpenCode Zen، Freebuff، OpenAI، Gemini، DeepSeek، Grok، Qwen، OpenRouter، Mistral، Groq، Cerebras، Together، Fireworks، Perplexity، Moonshot، Z.AI، NVIDIA NIM، SambaNova، GapGPT، AvalAI، Ollama، LM Studio یا هر آدرس سازگار با OpenAI)، یکی از مدل‌های پیشنهادی را می‌زنید یا نام مدل را خودتان می‌نویسید و مستقیم از نچ می‌پرسید. پاسخ کلمه‌به‌کلمه می‌آید و هر وقت خواستید متوقفش می‌کنید. Freebuff به‌جای API رسمی، از پروکسی محلی Freebuff2API استفاده می‌کند. کلید فقط در `qio.json` روی همین دستگاه می‌ماند و جز به همان سرویس به هیچ جا فرستاده نمی‌شود.
- **ابزارهای نچ** — تب «ابزارها» یک جعبهٔ ابزار محلی است: قهوه صفحه را بیدار نگه می‌دارد، ماشین‌حساب درصد و عبارت‌های فارسی («۲۰٪ روی ۱۵۰»)، تبدیل یکا و هگز/باینری را می‌فهمد و تاریخچه دارد، و مونیتور سیستم مصرف CPU، حافظه، شبکه و درایوها را نشان می‌دهد؛ نمونه‌گیری فقط وقتی تب دیده می‌شود انجام می‌شود، نه در پس‌زمینه.
- **اجرای سریع** — فایل، برنامه، پوشه یا سایت را یک‌بار در تنظیمات → اجرای سریع پین می‌کنید و بعد از همان تب «اجرا» با یک کلیک بازش می‌کنید. آیکون‌ها از خود ویندوز گرفته می‌شوند، ترتیبشان با دکمه‌های بالا/پایین عوض می‌شود و تا ۲۴ میانبر جا دارد. میانبرها فقط روی همین دستگاه در `qio.json` می‌مانند؛ برای سایت‌ها فقط نشانی‌های http و https پذیرفته می‌شود و آن‌ها با مرورگر پیش‌فرض باز می‌شوند.
- **انتخاب رنگ و قلم روی صفحه** — با `Ctrl+Alt+C` هر جای صفحه یک عکس ثابت گرفته می‌شود؛ روی هر پیکسل بروید کد رنگش را می‌بینید و با یک کلیک هگز در کلیپ‌بورد کپی می‌شود و در همان نشست در تب «صفحه» می‌ماند. با `Ctrl+Alt+D` یک لایهٔ شفاف روی کل صفحه باز می‌شود که با چند رنگ و ضخامت می‌توانید دور هر چیزی خط بکشید؛ Esc یا کلیک بیرون آن را می‌بندد.
- **تاریخچهٔ کلیپ‌بورد** — اگر خودتان روشنش کنید، متن و تصویرهای کپی‌شده در همان نشست در «قفسه» می‌مانند و با یک کلیک برمی‌گردند. این تاریخچه فقط در حافظه است و روی دیسک نوشته نمی‌شود.
- **چیدمان بنتو** — هر صفحهٔ نچ می‌تواند ۱×۱، ۲×۱ یا ۲×۲ باشد؛ ترتیب تب‌ها را با کشیدن عوض می‌کنید و هر تب را که نخواستید پنهان می‌کنید. نچ هم خودش را با همین چیدمان اندازه می‌گیرد. جای نچ هم قابل انتخاب است: وسط، چپ یا راست لبهٔ بالای صفحه.
- **به‌روزرسانی با کنترل SHA‑256** — Qio از گیت‌هاب نگارش تازه را می‌گیرد و می‌تواند نصب‌کننده را داخل خودش دانلود کند. پیش از هر اجرا هش SHA‑256 فایل با هشی که گیت‌هاب برای همان فایل گزارش می‌کند مقایسه می‌شود؛ اگر یکی نباشد فایل پاک می‌شود و نصب اصلاً شروع نمی‌شود. فقط پس از تأیید هش، نصب‌کننده بی‌صدا اجرا می‌شود و Qio دوباره باز می‌شود.
- **ظاهر زنده** — هر پنل رنگ خودش را دارد: هالهٔ آرام پشت نچ، محو شدن تصویر آلبوم پشت پنل آهنگ، حلقهٔ تمرکز با تیک‌های چرخان و نوار یادداشت‌های رنگی. صفحه‌ها با حرکت نرم وارد می‌شوند و اندازهٔ پنل با نمایشگر بزرگ یا کوچک هماهنگ می‌شود.
- **اورلی‌ها** — صدا، روشنایی، Caps Lock و تغییر زبان صفحه‌کلید یک کوچک زیر نچ نشان می‌دهند؛ باتری، شارژ و اتصال هدفون هم یک اعلان کوتاه می‌دهند.
- **ماسکوت** — یک جفت چشم روی نچ که پلک می‌زند، با حرکات ماوس نگاه می‌کند، با بی‌حرکتی خوابش می‌برد و با برگشتن شما سلام می‌کند. شکل، رنگ، اندازه، فاصله، سرعت پلک، مردمک، ابرو، گونه و بقیهٔ جزئیاتش را در بخش «ماسکوت» تنظیمات عوض می‌کنی.
- **سینی (Tray) و تنظیمات** — تنظیمات به نه دستهٔ کنارهم تقسیم شده — عمومی، چیدمان، ماسکوت، هوش مصنوعی، صدا و صفحه، اجرای سریع، آب و تمرکز، فوتبال، درباره — تا هر چیزی سر جای خودش باشد. حالت ساعت (همیشه پیدا یا هر چند دقیقه یک‌بار) و جای نچ در تنظیمات → عمومی است.
- **رابط فارسی و راست‌به‌چپ** — همهٔ پنل‌ها، منوها، اعلان‌ها و اورلی‌ها فارسی‌اند و با فونت وزیرمتن (همراه برنامه، بدون نیاز به اینترنت) نمایش داده می‌شوند.
- **میان‌بر کیبورد** — کلیدهای ۱ تا ۹ (لاتین یا فارسی) مستقیم به تب‌ها می‌پرند، «۰» به دهمین تب (روزی که تب بازی‌ها باز است)، کلیدهای جهت روی نوار تب‌ها جابه‌جا می‌کنند و Esc پنل را می‌بندد.

همهٔ داده‌ها به‌صورت محلی (یک فایل JSON در پوشهٔ دادهٔ برنامه) ذخیره می‌شوند؛ بدون حساب کاربری و بدون ردیابی. تنها ارتباط‌های شبکه، دریافت متن آهنگ از LRCLIB، دریافت بازی‌ها و رویدادهای فوتبال از ورزش۳، بررسی نگارش تازه و دریافت نصب‌کننده از گیت‌هاب، و ارسال پیام‌های هوش مصنوعی به همان سرویسی است که خودتان انتخاب کرده‌اید؛ کلید API در آن فایل محلی می‌ماند و در لاگ نمی‌آید. میانبرهای اجرای سریع هم فقط مسیر یا نشانی را در همان فایل نگه می‌دارند و هیچ‌کدام را جایی نمی‌فرستند؛ یک نشانی تنها وقتی به مرورگر پیش‌فرض داده می‌شود که خودتان روی آن کلیک کنید. اعلان‌های ویندوز فقط از پروندهٔ محلی همان سیستم خوانده می‌شوند و فقط در حافظهٔ Qio می‌مانند؛ هیچ‌کدام جایی فرستاده یا ذخیره نمی‌شود.

## نصب

### روش ۱: نصب‌کنندهٔ آماده (پیشنهادی)

1. به بخش [Releases](../../releases) مخزن بروید و فایل `Qio-Setup-x.y.z.exe` (یا ZIP آن) را دانلود کنید.
2. فایل را اجرا کنید. نصب بدون دسترسی Administrator انجام می‌شود (نصب فقط برای کاربر فعلی).
3. بعد از نصب، آیکون Qio در کنار ساعت دیده می‌شود و نچ بالای صفحه ظاهر می‌شود.

> اگر ویندوز هشدار «Windows protected your PC» را نشان داد: روی **More info** بزنید و سپس **Run anyway** را بزنید. این هشدار برای برنامه‌های جدید و امضا‌نشدهٔ عادی است.

برای حذف برنامه: **Settings → Apps → Qio → Uninstall**.

### روش ۲: ساخت از روی کد

پیش‌نیازها: **Node.js 20 یا جدیدتر** و **npm**، روی ویندوز ۱۰/۱۱ (۶۴ بیت).

```bash
git clone https://github.com/sahandse/qio.git
cd qio
npm install        # نصب وابستگی‌ها
npm run dist       # ساخت نصب‌کنندهٔ ویندوز (NSIS)
```

نصب‌کنندهٔ ساخته‌شده در پوشهٔ `release/` قرار می‌گیرد؛ آن را اجرا کنید و تمام.

## اجرا برای توسعه

```bash
npm install
npm run dev        # اجرای dev با hot reload
npm run typecheck  # بررسی انواع (tsc) روی پروژه‌های node و web
```

اجرای smoke-test و بررسی اتصال پل ویندوز:

```bash
QIO_SELFCHECK=1 npm run dev
```

یک خط وضعیت (آهنگ، صدا، باتری) در کنسول چاپ می‌شود.

### دستورهای دیگر

| دستور | کار |
| --- | --- |
| `npm run build` | ساخت خروجی نهایی در `out/` |
| `npm run start` | پیش‌نمایش نسخهٔ ساخته‌شده |
| `npm run icons` | بازتولید آیکون‌ها با `scripts/make-icons.mjs` |
| `npm run dist` | ساخت نصب‌کنندهٔ ویندوز (فقط روی ویندوز) |

## ساختار پروژه

```
src/main/        فرآیند اصلی الکترون: پنجره‌های نچ و اورلی، سینی، ذخیره‌سازی، اعلان‌ها، IPC
src/main/bridge.ts
                 اسکریپت resources/bridge/qio-bridge.ps1 را اجرا می‌کند (یک پروسهٔ
                 PowerShell بلندمدت) و از طریق سوکت TCP محلی با JSON هر خطی
                 (JSONL) با آن حرف می‌زند. این پل همان بخشی است که ویندوز را می‌شناسد:
                 پخش SMTC، صدا، روشنایی، Caps Lock، زبان صفحه‌کلید، باتری و شارژ.
src/preload/     API پل (`contextBridge`) که در اختیار رندرر است
src/renderer/    رابط کاربری React: نوار نچ و پنل‌ها + پنجرهٔ اورلی
src/shared/      انواع (Types) مشترک بین هر سه فرآیند
```

اسکریپت پل به‌عنوان منبع همراه برنامه ارسال می‌شود (`resources/bridge` → `bridge/` کنار فایل اجرایی)، پس در نسخهٔ بسته‌بندی‌شده از روی دیسک خوانده می‌شود و داخل `out/` بسته‌بندی نمی‌شود.
